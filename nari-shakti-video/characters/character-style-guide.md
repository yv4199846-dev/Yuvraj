# Character Style Guide
> **Project:** नारी शक्ति वंदन — Veo3 Video Series  
> **Style:** 2.5D animated, motion-graphic, cartoon illustration — symbolically recognizable, NOT photorealistic

---

## 1. PM Figure (प्रधानमंत्री प्रतीक)

| Attribute     | Description |
|---------------|-------------|
| Build         | Tall, dignified, broad-shouldered |
| Attire        | White kurta-pajama with saffron/orange shawl draped over shoulder |
| Hair          | White/grey, neatly groomed |
| Beard         | Full grey beard, well-trimmed |
| Eyes          | Confident, wise — deep-set |
| Posture       | Upright, commanding, hands often open (gesture of offering) |
| Color aura    | Warm gold and saffron glow around him |
| Usage         | Parts 1 only — shown at Parliament podium holding glowing document |

**Veo3 Style Tag:** `"dignified cartoon PM figure, white kurta, saffron shawl, grey beard, confident posture, 2.5D animated style"`

---

## 2. Rahul-like Opposition Figure (विपक्ष प्रतीक)

| Attribute     | Description |
|---------------|-------------|
| Build         | Tall, lean |
| Attire        | Plain white kurta-pajama |
| Hair          | Dark, wavy, slightly long |
| Face          | **ALWAYS shown from back or side profile — never full face** |
| Posture       | Arms raised in protest, or walking out of frame |
| Shadow        | Exaggerated dark shadow on wall behind him |
| Color aura    | Cold grey and dark blue tones |
| Usage         | Parts 3, 4 — shown walking out or protesting |

**Veo3 Style Tag:** `"tall cartoon figure in white kurta, dark wavy hair, back/side profile only, arms raised in protest, dark grey color tone, 2.5D animated style"`

---

## 3. Rural Woman (ग्रामीण महिला)

| Attribute     | Description |
|---------------|-------------|
| Build         | Medium, gentle presence |
| Attire        | Traditional saree — earthy red/orange/yellow |
| Hair          | Dark, tied in bun, adorned with flowers or simple pins |
| Face          | Sindoor on forehead, bindi, expressive warm eyes |
| Emotion range | Hope/joy (Parts 1–2) → Anger/demand (Parts 6–7) |
| Background    | Rural village, mud wall, small TV set |
| Color aura    | Warm golden-orange in early parts, red in later parts |

**Veo3 Style Tag:** `"rural Indian woman, saree, sindoor, expressive eyes, 2.5D cartoon illustration, warm golden tone"`

---

## 4. Urban Woman (शहरी महिला)

| Attribute     | Description |
|---------------|-------------|
| Build         | Slim, confident, modern |
| Attire        | Salwar-kameez or formal suit — muted jewel tones |
| Hair          | Dark, open or in ponytail |
| Face          | No sindoor, modern makeup, sharp determined eyes |
| Emotion range | Pride/joy (Parts 1–2) → Anger/demand (Parts 6–7) |
| Background    | City skyline, smartphone in hand |
| Color aura    | Warm orange in early parts, red in later parts |

**Veo3 Style Tag:** `"young urban Indian woman, salwar suit, confident posture, smartphone, 2.5D cartoon illustration, warm golden tone"`

---

## 5. Elderly Woman (बुज़ुर्ग महिला)

| Attribute     | Description |
|---------------|-------------|
| Build         | Shorter, frail but strong-willed |
| Attire        | White/light saree — simple, dignified |
| Hair          | White/silver, pulled back |
| Face          | Deep wrinkles, sharp eyes full of wisdom and fire |
| Emotion range | Appears only in Part 6 — full anger and demand |
| Color aura    | Red and gold |

**Veo3 Style Tag:** `"elderly Indian woman, white saree, silver hair, fierce wise expression, pointing forward, 2.5D cartoon illustration"`

---

## 6. Shadow/Opposition Figures (विपक्ष के काले साये)

| Attribute     | Description |
|---------------|-------------|
| Style         | Dark grey or black silhouettes — no clear faces |
| Posture       | Aggressive, blocking, arms outstretched to obstruct |
| Effect        | Blurred edges, smoky outlines |
| Logos         | Near them: blurred hand symbol (grey), blurred "I.N.D.I.A. Alliance" text |
| Color aura    | Cold dark grey, deep shadow |
| Usage         | Parts 3, 4, 5 |

**Veo3 Style Tag:** `"dark grey silhouette figures, blurred faces, ominous blocking posture, smoky outlines, cold dark grey tones, 2.5D animated style"`

---

## Global Animation Style Tags (use in every Veo3 prompt)

```
2.5D animated style, motion-graphic, cartoon illustration, Indian political symbolism, 
cinematic lighting, dynamic camera movement
```

## Color Grade Progression

| Parts | Palette |
|-------|---------|
| 1–2   | Warm gold, saffron, sunrise orange |
| 3–4   | Cold grey, dark blue, smoky |
| 5–6   | Deep red, black, high contrast |
| 7     | Dark sky + single warm light from Parliament (resolution) |
